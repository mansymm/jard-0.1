# 📦 تطبيق جرد المخزون الاحترافي (الإصدار 2.0)

تم إعادة تصميم الواجهة بالكامل لتعمل بنظام **الأقسام والتبويبات السفلية (4 شاشات مستقلة)** مثل تطبيقات الجرد العالمية:
1. **📦 شاشة الجرد:** مخصصة للعمل الميداني السريع مع أزرار `+` و `-` و `✓` والباركود.
2. **📊 شاشة التقارير:** طباعة A4، تصدير Excel، متابعة نسب إنجاز المصانع، ونسخ ملخص واتساب.
3. **🗂️ شاشة السجل (History):** أرشفة تلقائية ويدوية لكل الجرود السابقة وإمكانية فتحها أو طباعتها في أي وقت.
4. **⚙️ شاشة الإعدادات:** رفع ملفات السيستم، بيانات الفواتير، تخصيص اسم المكتب، نسبة التنبيه، والنسخ الاحتياطي.
